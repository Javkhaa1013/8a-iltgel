# ✍️ 8А Нийтлэл — Монгол хэлний бие даалтын систем

Сурагчид нийтлэл, эргэцүүлэл бичиж хуваарийн дагуу үе шаттайгаар илгээнэ. Багш үнэлж, шилдгийг нь сайтад нийтэлнэ.

🌐 https://iltgel-8a.vercel.app

## Хугацаа

- Сурагч зөвхөн **эхлэх өдрийн 00:00 – дуусах өдрийн 23:59** (Улаанбаатарын цаг) хооронд оруулна. Сервер шалгадаг тул компьютерийн цагийг өөрчилж залилах боломжгүй.
- Хугацаа дуусахаас өмнө хэдэн ч удаа засаж болно. Дууссаны дараа түгжигдэнэ.
- Өвчтэй г.м. тохиолдолд багш **тухайн сурагчид** хугацаа сунгана (сурагчийн нэр → ⏰ Хугацаа сунгах).
- Бичиж байгаа зүйл хэдэн секунд тутам **серверт ноорог** болж хадгалагдана (өөр утаснаас орсон ч үлдэнэ). Илгээсэнд тооцогдохгүй — "Илгээх" заавал дарна.
- Илгээхээ мартсан бол багшийн хүснэгтэд 📝 гарна. Багш ноорогийг харж **"Илгээсэнд тооцох"** боломжтой. Ноорог зөвхөн хугацаа нээлттэй үед хадгалагддаг.
- Илгээх бүр **хувилбар** болж хадгалагдана. Багш, сурагч хувилбаруудыг сонгож, өмнөхтэй нь харьцуулж харна. Текст засагдсан ч сэтгэгдэл аль хувилбар дээр бичигдсэн нь үлдэнэ.

## Сэтгэгдэл ба үнэлгээ

Текст дээр үг, өгүүлбэрээ сонгоод сэтгэгдэл бичнэ (зураг дээр ерөнхий сэтгэгдэл).

- 👩‍🏫 **Багш** — бүх бүтээлд, хэзээ ч. Үе шат бүрд албан ёсны оноо өгнө.
- 🙋 **Өөрийн үнэлгээ** — сурагч өөрийн бүтээлийг **шалгуурын хуудсаар** үнэлнэ.
- 👥 **Хөндлөнгийн үнэлгээ** — хугацаа дууссаны дараа 7 хоног, ангийн 2 найзынхаа бүтээлийг **нэргүйгээр**, шалгуурын хуудсаар.

Шалгуурын хуудас ([lib/rubric.ts](lib/rubric.ts)): 4 шалгуурыг 1-4-өөр (Сайжруулах хэрэгтэй / Дунд / Сайн / Маш сайн) үнэлж, **сайн тал** ба **сайжруулах зөвлөгөө**-г заавал бичнэ. Шалгуур нь шатаас хамаарна:
Ноорог-1 (гол санаа, төлөвлөгөө, жишээ, уншигдахуйц), Нийтлэл (гарчиг, бүтэц, жишээ баримт, үг хэллэг), Эргэцүүлэл (юу сурсан, хүндрэл ба шийдэл, цаашдын зорилго, үг хэллэг).
Дунджийг тухайн шатын оноонд шилжүүлж багшид лавлагаа болгож харуулна — албан ёсны оноог багш өгнө.

Багшийн самбарын дээд талд нээлттэй даалгавар бүрийн **илгээгээгүй хүүхдийн нэрс** (📋 хуулж ангийн групп руу явуулна), сунгалттай хүүхдүүд, **хөндлөнгийн үнэлгээгээ дуусгаагүй** хүүхдүүд гарна. **👥 Хөндлөнгийн үнэлгээ** табд хэн хэнийг үнэлэх ёстой, үнэлсэн эсэх, хэдэн үнэлгээ хүлээн авсныг харна.

## Хуулахаас сэргийлэх

1. Бүтээлийг зөвхөн **өөрөө болон багш** харна. Ноорог хэзээ ч нийтэд гарахгүй.
2. Хөндлөнгийн үнэлгээ **хугацаа дууссаны дараа** (бүтээлүүд түгжигдсэн үед) л нээгдэнэ. Хүн бүр зөвхөн 2 бүтээл үзнэ, нэр нь нууц.
3. Сунгалттай сурагч өөрийн сунгалт дуустал бусдын бүтээлийг үзэх боломжгүй.
4. Ангийн найз зөвхөн өөрийн бичсэн сэтгэгдлийг харна (бусдын үнэлгээнд автахгүй).
5. Эцсийн бүтээлийг багш зөвхөн **хугацаа дууссаны дараа** сайтад нийтэлнэ.
6. **Хуулбар шалгах**: хоёр сурагчийн текстэд ижил 5 үгийн хэллэг олон давхцвал багшид анхааруулна.
7. Бичих талбарт **хуулж тавьсан (paste)** тэмдэгтийн тоог бүртгэнэ.

## Нэвтрэлтийн хамгаалалт

Буруу код/нууц үгийн оролдлогыг мэдээллийн санд (`rate_limits`) тоолно — Vercel олон сервертэй ч нэг тоолуур.
- Сурагчийн код: нэг IP-ээс 10 минутад 40 буруу оролдлого (анги нэг Wi-Fi-аас орох тул бага тавиагүй). Бүх IP-ээс нийт 100 хүрвэл зөвхөн буруу оролдсон төхөөрөмжүүд түгжигдэнэ — нэг хүүхэд бүх ангийг түгжиж чадахгүй.
- Багшийн нууц үг: нэг IP-ээс 10 минутад 8.
- Зураг: хүн тутамд 10 минутад 40.

## Анги ба багш нар

Систем олон ангид зэрэг ажиллана. Анги бүр **өөрийн сурагч, хуваарь, үнэлгээтэй**.

- **Админ багш** — `TEACHER_PASSWORD` орчны хувьсагчийн нууц үгээр нэвтэрнэ. Бүх ангийг хардаг, анги нэмж/устгаж, ангийн багш нарыг үүсгэнэ. Самбарын дээд талын сонголтоор ажиллах ангиа сольно.
- **Ангийн багш** — админы үүсгэсэн нууц үгээр нэвтэрч, **зөвхөн өөрийн ангиа** хардаг. Нууц үг нь scrypt хэшээр хадгалагддаг тул буцааж харах боломжгүй.
- Хөндлөнгийн үнэлгээ зөвхөн **нэг ангийн дотор** хуваарилагдана.
- Хуваарь, оноо, сануулга, экспорт бүгд ангиараа тусдаа. Нийтлэгдсэн нийтлэлүүд нүүр хуудсанд хамт харагдана.
- Анги устгахын өмнө сурагчдыг нь устгасан байх ёстой (санамсаргүй устгахаас сэргийлнэ).

Шинэ анги: **Багшийн самбар → 🏫 Анги, багш**.

## Багшийн хэрэгслүүд

- **💡 Санал болгох оноо** — бүтээлийн оноо өгөх хэсэгт шалгуурын үнэлгээнээс тооцсон оноог (хөндлөнгийнх 75%, өөрийнх 25%) нэг товшилтоор бөглөнө. Эцсийн шийдвэр багшийнх.
- **⭐ Хэвшмэл сэтгэгдэл** — байнга бичдэг хэллэгүүд сэтгэгдлийн маягт дээр товч болж гарна. Өөрийн хэллэгээ хадгалж нэмж болно (тухайн браузерт).
- **⬇️ Бүх өгөгдлийг татах** — "Сурагчид ба код" хэсгээс сурагчид, бүтээл, хувилбар, сэтгэгдэл, үнэлгээ, зургийн холбоосыг нэг JSON файлаар татна (`/api/export`). Админ бүх ангийг, ангийн багш зөвхөн ангиа авна.
- **🔗 Эцэг эхийн холбоос** — сурагчийн хуудаснаас нууц холбоос хуулж өгнө. Эцэг эх нэвтрэхгүйгээр зөвхөн тэр хүүхдийн тайланг үзнэ (`/report/<id>.<токен>`), хайлтын системд индексгүй.

## Эцэг эхийн тайлан

Багшийн самбар → 📄 Тайлан. Онооны хүснэгт, илгээсэн огноо (хугацаандаа эсэх), гар бичмэл ноорогийн зураг, **Ноорог-2 → Эцсийн бүтээлд хийсэн өөрчлөлт** (нэмсэн/хассан үг өнгөөр), багшийн сэтгэгдэл, нийтлэгдсэн бол уншсан тоо. Хэвлэх эсвэл PDF болгоно.

## Эхлүүлэх

1. Багш `/teacher` → нууц үгээр нэвтэрнэ.
2. **Сурагчид ба код** → ангийн нэрсийг хуулж тавина → **🖨️ Код хэвлэх** → хүүхэд бүрт кодыг нь өгнө.
3. Сурагч `/login` → кодоо оруулна → **Миний даалгаврууд**.

## Зураг

Гар бичмэлийн зургийг **браузер дээр нь** шахаж серверт илгээнэ ([lib/uploadImage.ts](lib/uploadImage.ts)): урт тал 1600px, WebP (хуучин Safari-д JPEG), чанар 0.72-оос 0.45 хүртэл буурч ~300 КБ-д хүрнэ. Утасны 4-5 МБ зураг ≈0.2-0.3 МБ болдог тул Supabase-ийн үнэгүй 1 ГБ зайд хэдэн ангийн бүх ноорог хүрэлцэнэ. Серверт мөн файлын төрлийг эхний байтуудаар шалгана.

## Техник

Next.js 16 · Supabase (Postgres + Storage) · Vercel. Supabase тохируулаагүй бол `data/*.json`-д хадгална (локал туршилт).

```bash
npm install
npm run dev
```

`.env.local`: `TEACHER_PASSWORD`, `SESSION_SECRET`, (заавал биш) `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`.
Хугацааг туршихдаа: `DEV_NOW=2026-10-07T12:00:00+08:00` (зөвхөн хөгжүүлэлтийн горимд).

Хүснэгтүүд апп анх асахдаа автоматаар үүснэ ([lib/schema.ts](lib/schema.ts)). Шинэчлэх: `npx vercel deploy --prod`.

Supabase-ийн үнэгүй төсөл 7 хоног идэвхгүй бол зогсдог тул [vercel.json](vercel.json)-д Vercel Cron өдөр бүр `/api/cron/keepalive` руу хүсэлт илгээнэ (Улаанбаатарын 05:00 орчим).

Өмнөх слайд-илтгэлийн хувилбарын код: `backup/iltgel-slides-v1.zip`.
